**Dashboard de Assinaturas Xbox**
Dashboard desenvolvido como prática de um desafio do bootcamp da DIO, com foco na organização e visualização de dados de vendas de assinaturas de jogos Xbox.
**Objetivo**
Transformar dados brutos em informações visuais que facilitem a leitura do desempenho das assinaturas ao longo do tempo e apoiem uma análise mais clara dos resultados.
**Sobre o dashboard**
O dashboard apresenta o total de assinaturas por mês, trimestre e ano. Para destacar os resultados, foram selecionadas duas assinaturas relevantes para a análise visual das vendas geradas.
A visualização permite comparar os períodos e observar como os resultados se distribuem ao longo do tempo.
**Ferramenta utilizada**
Microsoft Excel
**Contexto**
Projeto desenvolvido como atividade prática do bootcamp da DIO, com o objetivo de praticar a organização e a apresentação visual de dados de vendas.
